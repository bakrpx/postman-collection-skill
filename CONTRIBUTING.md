# Contributing

## Reporting Issues

Open an issue on [GitHub](https://github.com/bakrpx/postman-collection-skill/issues) with the skill version, Claude Code version, and steps to reproduce.

## Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Commit and push (`git push origin feature/my-feature`)
5. Open a Pull Request

## Guidelines

### SKILL.md
- Keep under 400 lines
- Frontmatter must include `name` and `description` with trigger phrases
- All patterns must be generic — no project-specific data

### Reference Files
- One topic per file
- Include code examples for every pattern
- Keep patterns applicable to any Laravel project
